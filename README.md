# MyLab – Website

Vorstellung, Intranet-Anbindung, Datenschutz und Architektur von MyLab, dem Inventar- und
Ausleihsystem der Fachschaften Physik, Biologie und Chemie. Gedacht für GitHub Pages,
analog zur MySchool-Website.

Alle Screenshots stammen aus einer Demo-Version mit erfundenen Personen und gezeichneten
Geräten. Der Quellcode der App liegt nicht in diesem Repository.
